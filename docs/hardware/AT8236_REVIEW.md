# AT8236 接口与供电核对

依据塔克 AT8236 模块手册 V1.0、TK-AT8236-MD320A V1.0 原理图及 MC130 手册。原 PDF 保留在本机资料目录，不纳入仓库。当前底盘模型与标定状态见 [BASE_MODEL.md](BASE_MODEL.md)，实测接线见 [WIRING.md](WIRING.md)。

## 控制输入 H1

下表为厂家原理图针号，方向必须按实物 1 脚标记确认。软件 A/B 指 GPIO 控制组，不能仅凭插座朝向或线色判断。

| H1 针号 | 信号 | 工程配置的 X5 BOARD 脚 |
|---:|---|---:|
| 1 | BIN2 | 33 |
| 2 | BIN1 | 31 |
| 3 | AIN1 | 27 |
| 4 | AIN2 | 29 |

AT8236 不需要独立 STBY/EN。IN1/IN2 一高一低驱动两个方向，两低为滑行/休眠，两高为制动。整车前进方向以实测为准：当前右轮软件 A 组用 IN2，左轮软件 B 组用 IN1。

## 编码器/电源排针 H2

| H2 针号 | 信号 |
|---:|---|
| 1 / 2 | E2A / E2B |
| 3 / 4 | E1A / E1B |
| 5 | VIN 分压 ADC，不接普通数字 GPIO |
| 6 | GND |
| 7 | 5V 输出 |
| 8 | 3V3 输出 |

工程中的 E1/E2 分别指 X5 输入对 11/13、15/16；已实测对应左轮 B、右轮 A。厂家端子定义和软件输入组名称须分开核对，不能只因名称不同就改动已验证的接线。

## 六针电机接口

| 原理图针号 | MOTOR-A / J3 | MOTOR-B / J4 |
|---:|---|---|
| 1 | AO2 | BO2 |
| 2 | GND | GND |
| 3 | E1A | E2A |
| 4 | E1B | E2B |
| 5 | 5V（编码器电源） | 5V（编码器电源） |
| 6 | AO1 | BO1 |

MC130 手册说明配套反向六针线可连接塔克驱动板；带外壳款使用 PH2.0 转 XH2.54 线。不能根据用户列举的一串信号名称，就认定实际物理针序不兼容。其他线缆须按两端编号和导通关系核对。

MC130 编码器允许 3.3–5V 供电且输出带上拉；与 X5 3.3V GPIO 连接时需保持电平兼容。用户最终确认编码器为 3.3V。单独改供电时必须隔离插座的原 5V，不能把 3.3V 与 5V 并接。

## 电源路径

```text
VIN / DC 输入 → 板载开关 → VIN → 两路电机 VM / VOUT 级联输出
                              └→ 5V 降压 → 编码器电源
                                         └→ 3.3V 稳压 → POWER 灯
                                                       └→ PPTC → 驱动 VREF
```

- AT8236 整板输入范围 5.5–15V；5V/3V3 排针是输出，不是电机 VM 输入。
- MC130 电机额定 6V，建议工作范围 3–9V；用户已确认当前 VM 降压至不超过 9V。
- POWER 灯亮不能证明带载 VM 或 PPTC 后 VREF 正常。
- 更换控制器后已验证双向驱动与编码器反馈；旧板是否损坏没有独立电气测量，不记录为已确定的唯一根因。
